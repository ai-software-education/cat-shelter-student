# Cat-shelter-API
Задания на разработку приложения для приюта кошек

Проект разделен на 7 логических этапов, каждый из которых представлен отдельной веткой в репозитории для студентов:

main-task-1-foundation - Модуль №1: Базовый реестр животных — Проектирование фундаментальной сущности Cat и реализация стандартных CRUD-операций для учета питомцев приюта.
main-task-2-relations - Модуль №2: Управление владельцами и процессом усыновления — Внедрение сущности волонтеров/владельцев и настройка логики передачи животного (связь Many-to-One).
main-task-3-statistics - Модуль №3: Аналитика и статистическая отчетность — Разработка инструментов для агрегации данных: расчет среднего возраста животных, статистики по породам и эффективности процесса усыновления.
main-task-4-auth - Модуль №4: Безопасность и идентификация — Реализация механизмов аутентификации, хеширование конфиденциальных данных и защита эндпоинтов от несанкционированного доступа.
main-task-5-extension - Модуль №5: Ролевая модель и медицинский учет — Внедрение иерархического доступа (RBAC) и детализированного учета состояния здоровья через выделенную сущность HealthCard.
main-task-6-productivity - Модуль №6: Высокопроизводительный Reader-сервис — Оптимизация операций чтения данных, работа с индексами и архитектурные решения для обеспечения быстрого отклика системы при больших объемах выборки.
main-task-7-integration - Модуль №7: Внешние интеграции и мониторинг — Организация взаимодействия с ГИС «РосКотМониторинг» через защищенные внешние API, обработка сетевых исключений и таймаутов.

Внутри каждой ветки вы найдете постановку задачи в файле README.md и спецификацию OpenApi, которому должно соответствовать ваше решение.
Вся необходимая документация размещена в отдельном **[репозитории](https://github.com/ai-software-education/documentation)**

Для выполнения задания создайте свою ветку, заменив префикс main на другой префикс, по которому преподаватель сможет вас идентифицировать. Для этого выполните в терминале команду: 

``` bash
git fetch origin
git checkout -b first-team-task-0 origin/main-task-0
```
